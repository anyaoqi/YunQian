## 一句话定位

> 浏览器书签只解决「存下来」，云签解决「找得到、看得懂、用得上」。

## 版本速览

- **V1（已完成）**：本地单用户，书签/集合/标签的增删改查 + 浏览器书签导入 + 搜索 + JSON 导出。
- **V2（已完成）**：回收站、批量操作、元数据抓取（标题/描述/封面）、拖拽整理、快捷键。
- **v0.1.0（规划中）**：修改应用名称和文档、迁移到 Next.js（App Router）、UI 改版、部署 CI/CD。
- **v0.2.0（规划中）**：书签导航预览分享、AI 书签整理。

> V1/V2 为已交付的里程碑版本；自 v0.1.0 起切换为语义化版本号，详见 [05 版本路线图](./05-roadmap.md)。
