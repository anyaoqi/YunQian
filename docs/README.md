## 一句话定位

> 浏览器书签只解决「存下来」，LinkNest 解决「找得到、看得懂、用得上」。

## 版本速览

- **V1（今日可用）**：本地单用户，书签/集合/标签的增删改查 + 浏览器书签导入 + 搜索 + JSON 导出。
- **V2**：回收站、批量操作、元数据抓取（标题/描述/封面）、拖拽整理、快捷键。
- **V3**：多用户与鉴权、公开分享页、浏览器扩展、失链检测。
- **V4**：全文正文快照、向量语义检索、AI 自动打标与摘要、团队协作与权限。
