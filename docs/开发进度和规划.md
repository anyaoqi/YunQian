# 书签整合整理工具 — 开发进度和规划

> 本文件在开发过程中实时更新。最近更新：2026-06-27

## 一、项目目标
把多浏览器（Chrome / Edge / Firefox 等）、多电脑导出的书签**统统导入** → **整合去重** → **自动分类整理** → **手动微调** → **导出**一份统一书签，再导入回所有浏览器实现统一。

## 二、技术方案
- 形态：**纯前端单页应用**（无后端），数据全部存本机 IndexedDB，隐私好、可离线、一条命令启动。
- 技术栈：**Vite + React + TypeScript + Dexie(IndexedDB) + Zustand**。
- 整理：本地规则（去重 + 域名/关键词分类）为主，**可选 AI**（浏览器直连 Claude / OpenAI 兼容接口）增强。
- 互通格式：标准 **Netscape Bookmark HTML**（所有浏览器导入/导出通用）。

## 五、核心数据流
```
导入(多文件) → 解析为 Bookmark[] (打 source 标签)
  ├─ 默认模式：folderId=null → 去重 → 自动分组(本地规则 / AI)
  └─ 勾选「保留结构」：按 path 建嵌套文件夹树 → 分配 folderId
→ 手动编辑(拖拽书签/拖拽分组改父级/改名/新建子分组/移动/删除)
→ 自动持久化 IndexedDB
→ 导出 Netscape HTML (浏览器导入) / JSON 备份 (本工具恢复)
```

## 六、验证计划（端到端）
1. `npm install && npm run dev` 打开页面。
2. 导入 `sample/bookmarks-sample.html`（含重复与多文件夹），确认数量正确。
   - 默认模式：全部进入未分组。
   - 勾选「保留结构」：按原始文件夹层级显示（书签栏 > 开发/视频/购物/社交）。
3. 去重 → 看到合并数量；本地整理 → 生成分类文件夹树。
4. 拖拽书签到分组 / 拖拽分组到另一分组下 / 改名 / 新建子分组 / 删除，刷新后确认持久化生效。
5. 导出 HTML，导入 Chrome/Edge 确认目录与书签完整。
6. 导出 JSON 备份 → 清空 → 恢复备份 → 确认数据完整。
7.（可选）填入 Claude API Key 执行 AI 整理；断网/Key 错误时回退本地规则不报错。
